DEVELOPER CHECK / NO SIGN-IN

Can the browser read the video?

This diagnostic requests only bytes 0–1023 of the supplied public Drive video. It does not download the complete file, request OAuth access, or send video through the preview server.

  1. In your Google Cloud project, enable Google Drive API.
  2. Create a standard API key, not a service-account authorization key.
  3. Restrict it to Google Drive API and the website http://127.0.0.1:4173/*.
  4. Run node serve.mjs and open this page at http://127.0.0.1:4173/drive-api-check.html.

The video must already be shared with anyone who has the link. Do not paste an OAuth token, private key, or client secret here. If Google asks to enable billing, stop and review it before proceeding.

Used only in memory for this request, sent directly to Google in a header, and cleared from this input when submitted. Not saved to local storage or project files. Browser developer tools can still inspect requests.

Not tested. The existing Drive viewer is unchanged.

A successful check proves access to this fragment only. Playback, seeking, quotas, and browser compatibility still need verification before replacing the working iframe.
