Privacy, compatibility, and fallback

Requires a Service Worker-capable browser and a secure context (HTTPS in production or the local preview). The worker handles only this page's fixed virtual media URL. It forwards range requests directly to Google using X-Goog-Api-Key and streams their responses without waiting for the complete file.

The worker registration may remain installed, but it stores no key or media permanently and controls only /stream/. A restarted worker requests the key again from the same open tab. Closing the stream removes that tab's key and cancels its transfers. It does not cancel other tabs.

If CORS hides Content-Range, the worker makes one small metadata request to verify the file size, then constructs local range headers from that size, the requested range, HTTP 206, and Content-Length. Only the size is retained in session memory; the file must remain unchanged during playback. Invalid or contradictory responses still stop the session. Full download never starts automatically. The separate full-download test remains opt-in. Production key configuration is not part of this developer experiment.
