What this test does — and does not prove

The complete file is fetched directly from Google, then played from a temporary Blob URL. This is not progressive streaming, persistent caching, or an offline feature. Seeking tests the downloaded copy, not remote byte-range seeking. Browser developer tools can inspect API requests. A production site must configure a restricted application key so visitors do not need to enter one; this developer test intentionally does not store it.
